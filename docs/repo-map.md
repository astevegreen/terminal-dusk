## .claude

- `.claude/agents/Explore.md` - Fast read-only codebase search. Use to find files, symbols, usages or where something lives. Returns paths and short excerpts, never whole files.
- `.claude/agents/implementer.md` - Builds one GitHub issue or fixes one pull request, with tests, in its own worktree. Used by the night shift.
- `.claude/agents/reviewer.md` - Read-only review of one task's diff against its spec and the architecture rules. Returns PASS or a numbered list of concerns.
- `.claude/rules/app.md` - App and shell rules
- `.claude/rules/content.md` - Content rules
- `.claude/rules/engine.md` - Engine rules
- `.claude/rules/server.md` - Server rules

- `.claude/settings.json`
- `.claude/skills/art-prompts/SKILL.md` - Write image-generation prompts for cards from their data and the art style guide. Run as /art-prompts.
- `.claude/skills/card/SKILL.md` - Add or change a card in packages/content - data, test and history note. Use for any card work.
- `.claude/skills/handoff/SKILL.md` - Write a short hand-off note before ending a long session or switching devices. Run as /handoff.
- `.claude/skills/implement-issue/SKILL.md` - Implement one GitHub issue or fix one pull request end to end, with tests and a pull request.
- `.claude/skills/night-shift/SKILL.md` - Overnight coordinator for the ready queue. Run only as /night-shift.
- `.claude/skills/plan-tasks/SKILL.md` - Turn a promoted design decision into night-shift-ready GitHub issues. Run as /plan-tasks.
- `.claude/skills/promote/SKILL.md` - Copy approved design decisions and cards from Notion into the repo. Run as /promote.
- `.claude/skills/triage/SKILL.md` - Turn the week's playtest feedback into design questions and bug issues. Run as /triage.
